# 하늘까지 냥 (Fly Me to the Nyang) — 기획서 v1

> 옛 이름: 냥탑 (Nyang Tower)

> 위에서 좌우로 움직이는 고양이를 탭해서 떨어뜨리고, 최대한 높이 쌓는 픽셀 물리 게임.
> 한 판 1~4분, 룰 설명 없이 바로 이해되고, 끝나면 바로 다시 하고 싶어지는 게임.

- 장르: 원버튼 물리 쌓기 / 싱글 / 무한 (최고 기록 경쟁)
- 플랫폼: 브라우저 (모바일 세로 우선, PC 겸용)
- 화면: 세로 9:16, 내부 해상도 **180×320** 픽셀을 정수 배율로 업스케일
- 단위: 내부 1px = 1cm (화면에는 `3.42m`처럼 표시)

## ① 오브젝트 목록

### 고양이 10종 (쌓는 블록)
충돌 모양은 스프라이트를 단순화한 볼록 다각형/원. 크기는 내부 px 기준.

| # | 이름 | 모양(충돌) | 크기 | 질량 | 마찰 | 특징 | 등장 높이 |
|---|---|---|---|---|---|---|---|
| 1 | 식빵냥 | 둥근 직사각형 | 28×16 | 1.0 | 0.9 | 평평하고 안정적인 기본 블록 | 0m~ |
| 2 | 박스냥 | 정사각형 | 20×20 | 1.0 | 1.0 | 상자에 들어간 고양이, 가장 안정적 | 0m~ |
| 3 | 아기냥 | 작은 둥근 사각 | 12×10 | 0.4 | 0.8 | 작고 가벼움, 틈 메우기용 | 0m~ |
| 4 | 앉은냥 | 사다리꼴(아래가 넓음) | 16×24 | 1.0 | 0.8 | 세로로 높이를 벌어줌, 위는 좁음 | 0m~ |
| 5 | 동글냥 | 원 | r=9 | 0.9 | 0.5 | 동그랗게 말려서 굴러감 (난이도 요소) | 1.5m~ |
| 6 | 기지개냥 | 긴 직사각형 | 40×10 | 1.2 | 0.9 | 두 기둥을 잇는 다리 역할 | 1.5m~ |
| 7 | 뚱냥 | 큰 둥근 사각 | 32×22 | 2.0 | 0.9 | 무거워서 탑을 누르고 흔듦 | 3m~ |
| 8 | 엎드린냥 | 납작한 직사각형 | 36×8 | 0.9 | 1.0 | 아주 평평한 받침 | 3m~ |
| 9 | 귀쫑긋냥 | 오각형(위가 뾰족) | 18×22 | 0.8 | 0.7 | 위에 올리기 어려운 꼭짓점 | 7m~ |
| 10 | 우주냥 | 원+헬멧 | r=11 | 0.7 | 0.6 | 우주복 입은 고양이, 살짝 통통 튐(반발 0.3) | 12m~ |

**스프라이트 상태(종마다 공통):** 평온 / 눈깜빡 / 놀람(탑이 흔들릴 때) / 낙하(떨어질 때) + 크레인에 매달림 = 5프레임
**가끔 하는 행동:** 꼭대기 고양이가 하품하기, 옆 고양이 쳐다보기 (5~10초 랜덤, 연출만 하고 물리에는 영향 없음)

## ② 점수 · 진행 규칙 (경제 대신)

- **점수 = 탑의 안정 높이.** 고양이가 놓인 뒤 **1초 동안 속도가 0.05 미만**이면 '안착'으로 보고, 안착한 고양이 중 가장 높은 꼭대기 y를 높이로 삼음
- **최고 기록**은 현재 판에서 한 번이라도 찍은 최고 높이 (무너져도 줄지 않음)
- **하트 3개.** 고양이가 바닥 경계 아래로 떨어지면 1마리당 하트 -1, 0이 되면 게임오버
- **퍼펙트:** 놓은 고양이의 중심이 바로 아래 고양이 중심에서 ±2px 이내에 안착하면 반짝이는 효과 + 높은 "냥" 소리 (점수는 그대로, 순수하게 손맛용)
- **구간 도착:** 새 구간에 들어서면 배너("☁️ 구름 도착!")를 띄우고 배경이 바뀜

| 구간 | 높이 | 배경 | BGM 분위기 |
|---|---|---|---|
| 방 | 0 ~ 3m | 따뜻한 방, 창문, 화분 | 잔잔함 |
| 지붕 | 3 ~ 7m | 노을 지는 지붕, 빨랫줄 | 경쾌함 |
| 구름 | 7 ~ 12m | 하늘, 구름, 새 | 경쾌함 + 바람 소리 |
| 우주 | 12 ~ 20m | 별, 지구가 보임 | 몽환적 |
| 달 | 20m~ | 달 표면이 다가옴 → 착륙하면 엔딩 연출 후 계속 진행 | 몽환적 + 반짝임 |

### 기록과 수집 (localStorage)
- 역대 최고 기록
- **도감:** 고양이 10종과 구간 5개를 처음 만나면 "새 친구 발견!" 카드가 뜸
- **데일리 모드:** 날짜를 시드로 고양이 순서가 고정됨. 그날 데일리 최고 기록을 따로 저장

## ③ 난이도 곡선 (적 AI 대신)

| 요소 | 규칙 |
|---|---|
| 크레인 속도 | 시작 40 px/s, 고양이 5마리마다 +4, 상한 110 px/s |
| 크레인 이동 | 화면 폭 안에서 좌우 왕복 (가장자리 12px 여백). 15m부터는 속도가 사인파로 ±15% 흔들림 |
| 크레인 높이 | 항상 탑 꼭대기보다 110px 위 |
| 다음 고양이 | 놓은 뒤 0.7초 후 크레인에 새 고양이가 매달림 (연타 방지) |
| 고양이 뽑기 | 현재 높이에서 해금된 종만 가중치로 뽑음. 기본은 1~4번 위주, 동글냥은 15%를 넘지 않음, 같은 종 3연속 금지 |
| 바람 | 구름 구간(7~12m)에서만. 8초마다 2초간 좌 또는 우로 약한 힘(질량 1당 0.00025). 1초 전에 깃발과 구름이 미리 기울어서 예고 |
| 낮은 중력 | 우주 구간부터 떨어지는 속도만 0.8배 (쌓인 물리는 그대로) |
| 미리보기 | 다음 고양이 1마리를 화면 오른쪽 위에 표시 |

## ④ 조작 체계

| 입력 | 동작 |
|---|---|
| 화면 아무 곳 탭/클릭 | 고양이 놓기 |
| Space / Enter | 고양이 놓기 (PC) |
| P / Esc / ⏸ 버튼 | 일시정지 |
| R | 게임오버 화면에서 바로 재시작 |
| M / 🔈 버튼 | 소리 켜기/끄기 |

- 버튼(⏸, 🔈)을 누를 때는 고양이가 떨어지지 않게 해야 함 (입력 영역 분리)
- 카메라는 자동: 탑 꼭대기를 따라 부드럽게 올라감(lerp 0.08). 무너져서 높이가 낮아지면 천천히 내려옴
- 게임오버 화면에서는 탑 전체가 보이도록 카메라가 줌아웃

## ⑤ 화면 구성

```
┌──────────────────────┐
│ 3.42m        🏆 12.8m │  ← 현재 높이 / 최고 기록
│ ♥♥♡           NEXT 🐱 │  ← 하트 / 다음 고양이
│        ═╦═  🐈        │  ← 크레인 + 매달린 고양이
│                      │
│        🐈🐈           │
│       🐈🐈🐈          │  ← 탑
│      ▀▀▀▀▀▀           │  ← 방석
│ ⏸  🔈                 │
└──────────────────────┘
```

- **타이틀:** 로고, [시작] [데일리] [도감], 배경에서 고양이가 하나씩 떨어지는 데모 연출
- **구간 배너:** 화면 가운데에 1.5초 표시
- **게임오버:** 최종 높이, 최고 기록(NEW! 표시), 쌓은 고양이 수, 퍼펙트 수, [다시하기] [사진 저장] [타이틀]
- **사진 저장:** 줌아웃한 탑 전체 + 높이를 픽셀 카드 PNG로 다운로드
- **도감:** 4×3 그리드, 아직 못 만난 칸은 실루엣으로 표시

## 아트 · 사운드 · 손맛 방향

- 팔레트: 파스텔 32색 고정. 모든 스프라이트와 배경을 이 팔레트로만 그림
- 렌더링: 180×320 오프스크린 캔버스에 그린 뒤 `imageSmoothingEnabled=false`로 정수 배율 확대. 남는 여백은 구간 색으로 채움
- 스프라이트: MVP에서는 코드 안의 문자 그리드(팔레트 인덱스)로 정의하고, 나중에 PNG 시트로 교체할 수 있게 만듦
- 손맛:
  - 착지할 때 squash: 세로 0.85 → 1.05 → 1.0, 120ms
  - 착지 먼지 파티클 3~6개
  - 퍼펙트 착지 시 별 반짝임 + 화면 흔들림 1px
  - 탑이 크게 흔들리면 탑 위 고양이들이 놀란 얼굴로 바뀜
  - 낙하하면 0.4초 슬로모션 + 하트 깨지는 연출
- 사운드: WebAudio로 직접 합성 (외부 파일 없음)
  - 착지 "냥": 짧은 피치 벤드, 높이가 높을수록 음정이 올라감 (펜타토닉)
  - 퍼펙트: 위로 올라가는 3음 아르페지오
  - 낙하: 아래로 내려가는 소리
  - 구간마다 간단한 칩튠 루프

## 기술 구성

- **단일 HTML + ES 모듈, 빌드 도구 없음.** ES 모듈은 `file://`에서 막히므로 로컬 서버(`npx serve` 등)로 실행
- 물리: **Matter.js를 `vendor/`에 직접 넣어서 사용** (CDN 의존 없음)
- 렌더: Canvas 2D (이 규모에서는 WebGL이 필요 없음)
- 게임 루프: 고정 타임스텝 1/60초, 물리 서브스텝 2회, 프레임이 밀려도 한 번에 최대 5스텝까지만 따라잡음
- **로직과 렌더 분리:** `sim.js`는 DOM 없이 돌아가서 Node에서 headless로 테스트할 수 있어야 함
- 무작위: 시드 기반 PRNG (데일리 모드와 테스트 재현용)

```
index.html
css/style.css
vendor/matter.min.js
js/
  config.js    ← 모든 숫자(속도, 크기, 구간, 가중치)를 한 곳에
  sim.js       ← 물리 월드, 안착/낙하 판정, 점수, 하트
  spawner.js   ← 고양이 뽑기, 크레인, 난이도 곡선, 바람
  sprites.js   ← 팔레트 + 픽셀 스프라이트 데이터
  render.js    ← 저해상도 버퍼, 카메라, 배경, 파티클
  audio.js     ← WebAudio 효과음 + BGM
  input.js     ← 탭/키 입력
  ui.js        ← HUD, 타이틀, 게임오버, 도감, 사진 저장
  storage.js   ← localStorage (try/catch 필수)
  main.js      ← 루프 연결
tests/sim.test.mjs ← headless 시뮬레이션 테스트
```

## 성능 상한

| 항목 | 상한 | 지키는 법 |
|---|---|---|
| 목표 프레임 | 60fps (최악 장면에서도 55 이상, 중급 안드로이드 폰 기준) | 아래를 지키면 자연히 달성 |
| 최악 장면 정의 | "고양이 150마리 쌓임 + 탑 흔들림 + 파티클 150개 + 바람 + 우주 배경" | 이 장면에서 측정 |
| 움직이는 물리 바디 | ≤ 40개 | 화면 아래로 250px 이상 내려간 안착 고양이는 정적 바디로 **동결** |
| 프레임당 drawImage | ≤ 400 | 화면 밖 오브젝트는 그리지 않음, 배경은 구간별로 미리 렌더한 레이어 사용 |
| 파티클 | ≤ 150개 | 오브젝트 풀 사용, 넘치면 오래된 것부터 제거 |
| 물리 스텝 시간 | 프레임당 ≤ 4ms | 바디 수 상한 + 서브스텝 2회 |
| 메모리 | 프레임마다 새 배열·객체 생성 최소화 | 재사용 버퍼 |
| 첫 로딩 | 전체 용량 ≤ 300KB | 외부 이미지·사운드 파일 없음 |

## ⑥ 완료 기준 체크리스트

### 핵심 루프
- [ ] 페이지를 열면 타이틀이 뜨고, [시작]을 누르면 3초 안에 첫 고양이가 크레인에 매달려 좌우로 움직인다
- [ ] 화면을 탭하거나 Space를 누르면 고양이가 크레인에서 떨어진다
- [ ] 놓고 0.7초 뒤 다음 고양이가 크레인에 나타나고, 그 전에 다시 탭해도 아무 일도 일어나지 않는다
- [ ] 떨어진 고양이가 방석이나 다른 고양이 위에 물리적으로 쌓인다 (서로 통과하지 않는다)
- [ ] 고양이 10종의 충돌 모양이 각각 표에 적힌 형태대로 동작한다 (동글냥은 구르고, 박스냥은 잘 멈춘다)
- [ ] 고양이가 1초 동안 거의 정지하면 '안착'으로 판정되고 높이 표시가 갱신된다
- [ ] 고양이가 바닥 경계 아래로 떨어지면 하트가 1개 줄고, 3개를 모두 잃으면 게임오버 화면이 뜬다
- [ ] 최고 기록이 localStorage에 저장되어 새로고침해도 유지된다

### 진행 · 난이도
- [ ] 크레인 속도가 고양이 5마리마다 4px/s씩 올라가고 110px/s를 넘지 않는다
- [ ] 각 고양이 종은 정해진 높이에 도달하기 전에는 나오지 않는다
- [ ] 같은 종이 3번 연속으로 나오지 않는다
- [ ] 3m, 7m, 12m, 20m를 넘으면 배경이 바뀌고 구간 배너가 표시된다
- [ ] 바람은 7~12m 구간에서만 불고, 불기 1초 전에 시각적 예고가 나온다
- [ ] 같은 날짜의 데일리 모드는 매번 같은 고양이 순서로 나온다

### 카메라 · UI
- [ ] 크레인은 항상 탑 꼭대기보다 약 110px 위에 있고, 카메라가 부드럽게 따라간다
- [ ] ⏸ 또는 🔈 버튼을 눌러도 고양이가 떨어지지 않는다
- [ ] 일시정지 중에는 물리와 크레인이 멈춘다
- [ ] 게임오버 화면에 최종 높이, 최고 기록, 고양이 수, 퍼펙트 수가 표시되고, [다시하기]나 R을 누르면 즉시 새 판이 시작된다
- [ ] [사진 저장]을 누르면 탑 전체가 담긴 PNG가 다운로드된다
- [ ] 도감에서 만난 고양이는 컬러로, 아직 못 만난 고양이는 실루엣으로 보인다

### 연출 · 사운드
- [ ] 착지할 때 squash 애니메이션과 "냥" 소리가 나고, 높이가 올라갈수록 음정이 높아진다

## 난이도 조정 (v1.1, 플레이 피드백 "너무 어렵다")

조준 오차를 가진 자동 플레이어(`tests/difficulty.mjs`)로 측정. 같은 시드 8판씩.

| 조준 실력 | 조정 전 중간 기록 | 조정 후 | 3m 도달 | 7m 도달 |
|---|---|---|---|---|
| 잘 맞힘 (±2px) | 0.93m | 10.2m | 8/8 | 6/8 |
| 보통 (±4px) | 0.66m | 4.8m | 6/8 | 2/8 |
| 서툶 (±6px) | — | 1.9m | 2/8 | 0/8 |

원인 → 조치:
- 낙하의 2/3가 방금 놓은 고양이가 튕겨 나간 것 → 첫 착지 순간 속도 65% 흡수(`landDamp`), 낙하 높이 110→75px, 마찰↑·반발 0
- 꼭대기가 좁은 고양이 → 앉은냥 16×24→18×22(윗면 8→12px), 아기냥 12×10→14×11
- 7m 벽: 귀쫑긋냥의 뾰족한 꼭대기 위에 아무것도 못 올림 → 꼭대기 8px 평평하게
- 키 큰 고양이가 쓰러진 채 굳어 경사면이 됨 → 회전 관성 2.5배 (원형 제외)
- 한 번 무너질 때 하트가 여러 개 날아감 → 1.5초 안 연쇄 낙하는 하트 1개 (`collapseGrace`)
- 그 외: 방석 64→80px, 크레인 40→32px/s 시작·상한 110→90, 동결 깊이 160→100px, 바람 절반, 동글냥 해금 1.5m→3m
- 보상: 새 구간 도착 시 하트 1개 회복 (최대 3)
